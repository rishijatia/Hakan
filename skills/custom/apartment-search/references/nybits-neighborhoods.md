borough. Use these values in the `nei` checkbox array when filling the form via JS.

## Note on inventory
NYBits is strongest in LIC waterfront (TF Cornerstone buildings) and some
Downtown Brooklyn. Manhattan coverage is broad but listings are sparse.
Brooklyn outside downtown has very few entries.
