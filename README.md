# Hakan 🧠

Custom configurations, skills, and personalizations for **Hermes Agent**, tailored for Rishi Jatia.

## Structure

```
Hakan/
├── skills/
│   ├── custom/       # Skills built from scratch for Rishi's workflows
│   └── overrides/    # Modified versions of built-in skills
├── config/           # Agent config templates and presets
├── scripts/          # Automation scripts and utilities
└── templates/        # Reusable templates (plans, docs, etc.)
```

## What Goes Here

- **Custom skills** — domain-specific workflows, shortcuts, personal automations
- **Config overrides** — model preferences, tool settings, persona tweaks
- **Scripts** — helper scripts for cron jobs, integrations, monitoring
- **Templates** — plan templates, doc skeletons, project scaffolds

## Usage

Skills and configs in this repo are designed to be symlinked or copied into `~/.hermes/` as needed.
